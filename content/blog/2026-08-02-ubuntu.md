For the last few months, I have had the chance to experiment working full time under Linux. The experience was so smooth that it slowly rewired my mental model about what desktop productivity should look like, and made me wonder: why not try it at home?

<!--more-->

In this post, I want to share how I feel about the change.

#### What took me so long?
As a student and in my early career, I have always owned a personal computer with Windows running on it. This is because new, affordable computers always came with Windows pre-installed. All my needs were fulfilled:
- Plug and play
- Easy file management
- Academic software compatibility (Microsoft Office, MATLAB, Python, Siemens NX, LTspice, etc.)
- Gaming
- Drivers working out of the box (in general)

So back then everything was fine as-is; I didn't see any need to change anything. It's only recently that I decided to switch to Linux on my PC, for the following reasons:
- I have had a great experience of software development under Linux at my current job
- I started to feel annoyed by Windows 11 features (Copilot, overnight or sudden updates, ads, etc.)
- I was not gaming and had no plans to do so anymore
- I wanted to bring hardware upgrades to my PC (RAM, SSD, GPU) so it was a good moment
- You Only Live Once

#### My pick: [Ubuntu Desktop](https://ubuntu.com/desktop)
The Linux distribution I chose is [Ubuntu Desktop](https://ubuntu.com/desktop). It's a good match for my needs: it offers an accessible setup process, is easy to use, and is widely adopted. It's also commonly recommended for beginners. So I went ahead and downloaded the ISO image then ran the installation from a USB key.

#### First impressions
I was initially skeptical about setting up Ubuntu for personal use as I had developed strong habits under Windows. I was also scared that the user interface would be... ugly. This is because my only experience with Linux for personal projects was the Raspberry Pi and I was not a big fan of how its desktop GUI was laid out.

Those fears quickly dissipated. GNOME's clean, minimal design felt sophisticated rather than stark once I got used to it. In fact everything felt responsive and well-thought-out from day 1. The desktop is so clean, it feels like using an iPhone!

Although it has only been a few weeks, I am already very satisfied with my new desktop environment. I can only recommend it.

#### Conclusion and references to get started
The initial hesitation to abandon Windows faded into admiration for Ubuntu's balance of power and simplicity. Now, I find myself marveling at how a system once deemed "too technical" has become my preferred environment for both work and creativity!

I'd like to recommend these resources if you plan to migrate to Ubuntu:
- [Official Ubuntu documentation](https://ubuntu.com/desktop/docs/en/latest/)
- [A straightforward tutorial by ZacsTech on YouTube](https://www.youtube.com/watch?v=fHm2ddTsZkk)
- *Learning the Bash Shell* by Cameron Newham & Bill Rosenblatt
